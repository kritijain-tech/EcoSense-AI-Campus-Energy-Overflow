# ⚡ EcoSense AI
### Campus Energy Monitoring, Prediction & Anomaly Detection

## About the Project

EcoSense AI is a machine learning-based campus energy analytics application designed to explore electricity consumption patterns, identify unusual energy usage, and support informed energy management decisions.

Developed using Python and Streamlit, the application combines data analysis, predictive modeling, and interactive visualizations within a centralized dashboard.

The project demonstrates how machine learning and analytical techniques can be applied to energy monitoring in educational institutions.

## Key Features

**Energy Monitoring**
- Overview of campus electricity consumption.
- Building-wise energy analysis.
- Estimated electricity cost calculations.

**Energy Analytics**
- Interactive consumption trends.
- Historical energy usage analysis.
- Date-based and building-specific filtering.

**Machine Learning Predictions**
- Energy consumption prediction using machine learning.
- Comparison of actual and predicted consumption.

**Anomaly Detection**
- Identification of unusual energy consumption patterns.
- Adjustable anomaly detection sensitivity.

**Recommendations & Reporting**
- Energy management recommendations.
- Dedicated reporting section for energy-related insights.

## Dataset

The application uses a synthetically generated dataset that simulates campus electricity consumption.

This dataset supports experimentation with energy analytics, prediction, and anomaly detection without requiring access to real-world campus energy records.

The results are intended for demonstration and educational purposes.

## Installation and Setup

**1. Clone the repository**

```bash
git clone https://github.com/kritijain-tech/EcoSense-AI-Campus-Energy-Overflow.git
```

**2. Navigate to the project directory**

```bash
cd EcoSense-AI-Campus-Energy-Overflow
```

**3. Install dependencies**

```bash
python -m pip install -r requirements.txt
```

**4. Run the application**

```bash
python -m streamlit run app.py
```

The application will launch in a web browser.
